## 🛠️ Core Infrastructure & Projects

### 🌐 1. Machine-to-Machine Web Protocols (CBOR-Web)
* ⚡ **[cbor-web](https://github.com/ploteddie-bit/cbor-web)** — Binary web content format for autonomous AI agents based on CBOR (RFC 8949).
* 📖 **[cbor-web-read](https://github.com/ploteddie-bit/cbor-web-read)** — CBOR-Web Read Protocol: One file, one request, the entire website.

### 🧠 2. Agentic Harnesses & LLM Integrations
* 🌲 **[arbor-kimi-cli-provider](https://github.com/ploteddie-bit/arbor-kimi-cli-provider)** — LLM backend provider enabling the Arbor autonomous research framework to be piloted by Kimi Code CLI.
* 🚀 **[kimi-autoimprove-starter](https://github.com/ploteddie-bit/kimi-autoimprove-starter)** — Starter kit for self-improving agent context and memory harnesses in Kimi Code CLI.
* 🧩 **[skills](https://github.com/ploteddie-bit/skills)** — Modular collection of agentic skills for Kimi, Aegis, and AI coding assistants.

### 🛡️ 3. Security, Trust & AI Governance
* 🛡️ **[keysentinel](https://github.com/ploteddie-bit/keysentinel)** — Behavioral trust boundary architecture for API keys and MCP (Model Context Protocol) tools.
* ⚖️ **[reglement-intelligence-artificielle-europe](https://github.com/ploteddie-bit/reglement-intelligence-artificielle-europe)** — Tools and compliance frameworks aligned with the European Union AI Act.
